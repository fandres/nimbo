# Marca Nimbo

nimbo.svg reproduce en vectores la variante «Icono de app» del diseño
«Logo Nimbo · A refinada», proporcionado por el usuario para 0.6.0-beta.2.
Se usa en ventanas y como marca predeterminada cuando no existe logo de negocio.
packaging/nimbo.svg conserva la misma versión para AppImage; nimbo.ico contiene
resoluciones 16, 24, 32, 48, 64, 128 y 256 para Windows.
