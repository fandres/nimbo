# Nimbo 0.5.0-beta.1

Primera beta pública para evaluación de Nimbo: gestión local de ventas, compras,
inventario, gastos y dinero para emprendedores.

## Descargas

- **Debian 13, Intel/AMD 64 bits:** `Nimbo-0.5.0-beta.1-linux-x86_64.AppImage`.
- **Windows 11, Intel/AMD 64 bits:** `Nimbo-0.5.0-beta.1-windows-x86_64.zip`.
  Extrae todo el ZIP y abre `Nimbo.exe`; conserva `_internal` junto al ejecutable.
- **Fuentes y licencias:** `Nimbo-0.5.0-beta.1-sources.zip`.
  Este archivo incluye las fuentes de dependencias de la distribución; los ZIP
  automáticos de GitHub contienen únicamente el repositorio de Nimbo.
- Los archivos `.sha256` permiten comprobar la integridad de cada descarga.

## Incluye

- Catálogo configurable, ventas con seguimiento de cobros, comisiones y envíos.
- Compras, costos por modelo, recepción de pedidos y control de inventario.
- Gastos, adjuntos, préstamos, cuentas y control opcional de tarjetas.
- Informes PDF de ventas, gastos, dinero y rentabilidad FIFO.
- Copias completas de seguridad y restauración de base y documentos.
- Inicio con acciones diferenciadas por color y resaltado al pasar el cursor.

## Antes de actualizar

Crea un respaldo completo, cierra la versión anterior y conserva la carpeta de
datos y documentos. La actualización desde el esquema 24 de alfa 0.4 al 25 se
ha probado con datos ficticios. No abras la alfa antigua sobre la base migrada.

## Validación y limitaciones

468 pruebas automatizadas aprobadas en Linux local, Debian 13 aislado y
Python/Qt de Windows bajo Wine. Ambos paquetes pasan la prueba de arranque con
base temporal. La validación de esta beta en escritorios reales Debian 13 y
Windows 11 sigue pendiente. El ejecutable de Windows no está firmado.

No incluye contraseña de acceso, códigos de barras ni lectura automática de
facturas/XML. No emite facturas electrónicas ni se conecta a la DIAN. Los costos
incompletos son provisionales; los registros sin costo trazable se identifican
como tales en Rentabilidad.
