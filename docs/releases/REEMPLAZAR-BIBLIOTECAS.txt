Nimbo — uso de bibliotecas modificadas (LGPLv3)

Los binarios Qt, PySide6 y Shiboken se conservan dinámicos, sin verificaciones
que impidan reemplazarlos. No es necesario modificar la base de datos.
Use siempre una copia de prueba y conserve las interfaces y arquitectura x86-64.

WINDOWS
Extraiga el ZIP completo. En Nimbo/_internal/PySide6 están los módulos .pyd,
las DLL de Qt y los plugins; en _internal/shiboken6 está Shiboken.
Cierre Nimbo y reemplace las bibliotecas que modifique por versiones ABI/API
compatibles, conservando nombres y estructura. Ejecute Nimbo/Nimbo.exe.
Para un cambio de ABI reconstruya desde las fuentes adjuntas usando Python 3.13
para Windows y packaging/build.py, adaptando de forma explícita las versiones
fijadas si es necesario. No se requiere firma ni clave del autor de Nimbo.

LINUX
Extraiga el AppImage en una carpeta propia:
  chmod +x Nimbo-0.5.0-beta.1-linux-x86_64.AppImage
  ./Nimbo-0.5.0-beta.1-linux-x86_64.AppImage --appimage-extract
Dentro de squashfs-root/usr/_internal/PySide6/Qt/lib están las bibliotecas Qt;
los módulos PySide6 y Shiboken están en los respectivos directorios de _internal.
Reemplace bibliotecas y plugins por versiones compatibles. Ejecute:
  ./squashfs-root/AppRun
No es necesario volver a crear el AppImage para ejecutar la copia modificada.
Para cambios de ABI, reconstruya desde las fuentes con Python 3.13 y PySide6,
adaptando las comprobaciones de versión de packaging/build.py si corresponde.

FUENTES Y RECONSTRUCCIÓN
Consulte el archivo Nimbo-0.5.0-beta.1-sources.zip entregado junto a los binarios.
Incluye código de Nimbo, scripts de empaquetado y fuentes de las bibliotecas.
Las instrucciones oficiales de construcción están en los README y documentos
contenidos en cada archivo fuente. Los manifiestos de la entrega indican las
versiones utilizadas; las bibliotecas no se han modificado para Nimbo.
Las dependencias externas del sistema operativo deben estar disponibles.
