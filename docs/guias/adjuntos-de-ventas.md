# Documentos adjuntos de ventas

Después de guardar la venta, abre **Ventas → Movimientos** y pulsa el icono de clip de su fila. También está disponible en el detalle de la venta.

- **Adjuntar archivos** permite elegir uno o varios PDF, XML, PNG o JPG/JPEG.
- Nimbo guarda copias junto a la base de datos en `Documentos/AÑO/MES/Ventas/sale-ID/`, según la fecha de la venta. El archivo original no se modifica.
- El listado conserva el nombre original. Cada copia tiene un nombre interno único para evitar sobrescrituras.
- **Abrir** usa el visor predeterminado del equipo. **Ver carpeta** muestra la carpeta de la copia seleccionada.
- **Quitar** pide confirmación y retira el vínculo visible. La copia física permanece para poder recuperarla.
- El número junto al clip indica cuántos adjuntos activos tiene la venta.

Los respaldos de Configuración incluyen estos documentos. El XML se almacena como adjunto; todavía no se interpreta ni se utiliza para rellenar ventas automáticamente.
