# Catálogo — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Entregar un catálogo local usable de productos y servicios con interfaz moderna y persistencia SQLite.

**Architecture:** Qt Widgets presenta formularios y tabla; un módulo de dominio valida los datos; un repositorio SQLite realiza operaciones atómicas. Los datos viven en QStandardPaths.AppDataLocation, fuera del ejecutable y del repositorio.

**Tech Stack:** Python, PySide6, sqlite3, Decimal; pytest y pytest-qt para comprobaciones.

**Spec:** ../specs/2026-10-17-catalogo-design.md, incluyendo las anotaciones del usuario sobre logo, productos y códigos numéricos con ceros iniciales.

## Restricciones generales

- Interfaz en español, COP, tema claro, acento azul, inicio 1100 × 720 y mínimo 800 × 560.
- Códigos comerciales como texto: 001, 002, 010, 100 y 300 se conservan exactamente. El identificador interno es independiente.
- No generar códigos comerciales, borrar definitivamente ni simular existencias.
- Productos como tipo predeterminado; servicios disponibles.
- Dinero en centavos enteros, conversiones con Decimal; máximo dos decimales.
- No tocar datos reales en pruebas. No agregar datos ficticios al arranque.
- Logo opcional suministrado por el usuario: se muestra el nombre si falta, sin inventar una marca. El futuro flujo de ventas queda conservado en la especificación.

## Focos de revisión

1. Precios negativos, no finitos, demasiado grandes o con más de dos decimales deben rechazarse sin escrituras; tarea 1.
2. Códigos con ceros, diferencias de mayúsculas y caracteres de búsqueda SQL deben conservarse y buscarse literalmente; tareas 1–2.
3. Base de datos bloqueada, sin permisos o con versión futura debe mostrar un error sin reemplazar información; tareas 2 y 4.
4. Cancelación y guardado de registros que salen del filtro no deben confundir al usuario ni modificar datos inesperadamente; tarea 3.
5. Rutas con espacios, ausencia de logo y pantalla pequeña deben permitir abrir y utilizar la aplicación; tarea 4.
