# Informes Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Central de informes con vista previa y PDF de Ventas, Gastos y Dinero.
**Architecture:** Renderizador puro de Gastos; panel reutilizable de filtros y documento, compuesto en ReportsPage; integración en navegación existente.
**Tech Stack:** Python, PySide6, SQLite existente.
**Spec:** docs/superpowers/specs/2026-11-06-informes-design.md

## Global Constraints
Sin migraciones ni dependencias nuevas. Solo lectura. Mes actual, fechas visibles, filtros independientes. PDF igual a vista previa. Gastos estimados y crédito identificados; anulados excluidos de totales.

## Review Focus
- Rangos inválidos o fallos de consulta nunca exportan datos anteriores.
- Cargos a tarjeta no se presentan como efectivo pagado.
- Búsqueda y nombres con HTML no cargan recursos.
- Cuentas/categorías desactivadas con historial siguen consultables.
- Exportación cancelada o fallida preserva documentos existentes.
